# 日本語の改行・可読性チェックリスト

最終更新: 2026-10-23

このルールは、新規ページ、既存ページの更新、コラム本文・一覧カードの自動生成、テンプレート更新のすべてに適用する。

## 守ること

1. 見出し・本文・カード・バナー・ボタン・FAQ・図内テキストを、PC 1440px / 1280px / 768px、スマートフォン 390px / 375px / 360px / 320px で確認する。
2. `。`、`、`、助詞、1〜2文字の語尾だけを最終行に残さない。収まらない場合は、意味のまとまりごと次行へ移し、最終行にも自然な長さを確保する。
3. 読点の位置だけを理由に機械的な `<br>` を追加しない。不要な `<br>`、改行を生む `span`、狭すぎるテキスト領域、過剰な内側余白を最初に確認する。
4. 意図的な段落・詩的な改行は残してよい。ただし、対象幅で短い語尾だけが残らないことを確認する。
5. 文字を小さくする、全体を `nowrap` にする、極端な字詰め・変形・省略、横スクロールで解決しない。本文・説明文は原則16px以上、補助情報は14px以上を目安とする。
6. 禁則処理だけでは十分ではない。表示後の行分割を目視し、短い末尾行を別途点検する。
7. `assets/js/japanese-line-wrap.js` は、通常テキストと段落内の意図的な改行を含むテキストで、1〜2文字の末尾行を避ける補助処理である。原稿・テンプレートの意味のまとまりを置き換えるものではない。新規テンプレートにも読み込ませ、強制改行の直後に短い語尾が残る場合はHTML/CSSで個別に整える。
8. `display:flex` または `display:grid` のリスト・ボタン・カードは、補助処理が文字列を別の要素として囲むことでレイアウトを壊さないよう自動分割の対象外にする。語句を守る必要がある場合は、`jp-keep` を必要最小限の意味のまとまりにだけ付け、指定幅で横はみ出しがないことを確認する。
8. 自動生成するコラム・カードは、タイトル、抜粋、著者情報、フッターを含め、生成後に指定幅で確認する。テンプレート側で不自然な固定改行を生成しない。

## 完了前の確認

- 文字欠け、重なり、横スクロールがない。
- 指定幅間で修正が別幅の不自然な改行を生んでいない。
- Google Fonts読み込み後も確認する。
- ブラウザ拡大時にコンテンツが切れない。
- 原稿・数値・リンク・フォーム動作を変更していない。
- 未解消の箇所と、確認していない環境を報告する。
