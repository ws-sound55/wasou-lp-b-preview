# 共通ナビゲーション運用ルール

最終更新: 2026-10-23

## 標準の名称・順番

PCヘッダーおよびスマートフォンメニューは、原則として次の順にします。

1. なぜファミリー企業（`/family/`）
2. 私たちの想い（`/philosophy/`）
3. サービス（`/service/`）
4. ファミリーガバナンス（`/family-governance/`）
5. セミナー（`/seminar11/`）
6. コラム（`/column/`）
7. 会社概要（`/company/`）
8. ご相談・お問い合わせ（`/contact/`）

フッターには上記に加え、トップページ、サイトマップ、プライバシーポリシー、特定商取引法に基づく表記を掲載します。ページ本文のH1・本文見出しは、このラベル変更の対象外です。

## 表示・操作

- PCナビは1100pxを超える幅で表示し、狭い幅では文字を縮小せずハンバーガーメニューに切り替える。
- モバイルメニューは一列。開閉時の`aria-expanded`、Escapeでの閉じる操作、フォーカス移動、背景スクロール停止、フォーカス表示を必ず確認する。
- 現在地は`aria-current="page"`で表す。
- 新規コラムは`npm run build:columns`のテンプレートからメニューを生成する。旧表記「支援の理由」「支援する理由」「ファミリー企業を支援する理由」をメニューへ戻さない。

## 用途別の例外

- `seminar11/`は、PCでは申込CTAとページ内案内を優先して維持する。スマートフォンでは共通サイトメニューを併設する。
- 問い合わせ完了ページは、完了メッセージを優先する簡潔なフッターを維持できるが、スマートフォンの共通メニューとPCの主要導線を確認する。
- 転送専用URLと404には通常メニューの追加を必須としない。
- 非公開化済みの旧LP・旧セミナー・アーカイブ用URLは、公開維持ページのナビゲーション統一対象に含めない。再公開を承認された場合だけ、現行の標準メニューを適用する。

## 確認幅

PC 1440 / 1280 / 1024 / 768px、スマートフォン 390 / 375 / 360 / 320pxで、重なり、欠け、短すぎる改行、横スクロール、タップ領域、キーボード操作を確認する。
